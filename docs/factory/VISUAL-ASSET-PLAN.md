# Visual Asset Plan

Esta sub-fase (03A) condicional é executada se a Art Direction definir a necessidade de usar imagens geradas para atmosferas, fundos ou assets de design não comerciais/não reais.
Nenhum case/pessoa real deve ser inventado aqui.
