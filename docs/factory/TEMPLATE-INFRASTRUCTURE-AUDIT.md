# Template Infrastructure Audit V2 - Completion

## 1. Executive Summary
A auditoria final confirmou que o starter da Z-Agent está altamente limpo e livre de dados residuais de clientes. Confirmamos que o design inicial da infraestrutura não deve focar em criar "frameworks internos" ou antecipar componentes não essenciais (como abstração de Page Layouts ou Mobile Menus complexos para single-pages). O foco do CORE é resolver apenas problemas estruturais repetidos. Duas inconsistências cruciais foram confirmadas: o SEO metadata com valor perigoso (default "Create Next App") e uma severa cisão arquitetural no design system (tokens inline no TypeScript vs Variáveis Tailwind no CSS).

## 3. Identificar o P0 Real
- **P0_01**: Default Metadata Perigoso
- **TITLE**: Atualizar SEO Genérico no Layout Root
- **FILE_OR_AREA**: `app/layout.tsx`
- **EVIDENCE**: `title: "Create Next App", description: "Generated by create next app"` fixados diretamente no root metadata.
- **WHY_P0**: Este é um valor padrão perigoso que pode ser acidentalmente enviado para produção, fazendo com que o site real do cliente seja indexado no Google como "Create Next App".
- **RISK_IF_NOT_FIXED**: MUST FIX BEFORE USING THIS STARTER FOR A REAL NEW PROJECT. Se não for corrigido, afeta SEO e credibilidade instantaneamente.
- **MINIMAL_DIRECTION**: Conectar a prop `metadata` do `app/layout.tsx` para ler dinamicamente de `data/site.config.ts`.

## 4. Identificar o P1 Real
- **P1_01**: Dualidade de Design System
- **TITLE**: Unificar Brand Tokens (TS) e Tailwind Variables (CSS)
- **FILE_OR_AREA**: `data/brand.ts` vs `app/globals.css`
- **EVIDENCE**: `data/brand.ts` define `colors.primary = "#1F2937"`, que é usado via inline-style no `page.tsx`. Porém, `app/globals.css` define `--primary: oklch(0.205 0 0)` que é usado pelo Tailwind v4 e Shadcn components (`components/ui/button.tsx`).
- **WHY_P1**: Se a configuração de marca for alterada em `brand.ts`, os componentes Shadcn não respeitarão a mudança, resultando em um site fragmentado.
- **RISK_IF_NOT_FIXED**: SHOULD FIX BEFORE THE FIRST NEW PROJECT. Não quebra o app, mas destruirá o Visual QA e exigirá debug de CSS em todo novo projeto.
- **MINIMAL_DIRECTION**: `brand.ts` deve idealmente alimentar as variáveis Tailwind ou as definições de cor de `globals.css` devem ser a única fonte de verdade.
