# Catálogo de Direções Visuais — Z-Agent

Este documento define direções visuais que podem ser escolhidas para cada projeto.

A direção escolhida deve influenciar de forma perceptível:
- composição
- grid
- tipografia
- Hero
- cards
- imagens
- espaçamento
- bordas
- formas
- hierarquia
- ritmo visual
- microinterações

Não interpretar estilos diferentes apenas como troca de cores.

---

## Sistema obrigatório de aplicação da direção visual

A direção visual escolhida não é um tema ou skin aplicado sobre uma estrutura padrão.

Ela deve modificar concretamente a arquitetura visual do projeto.

Antes de implementar, traduza a direção escolhida em decisões específicas para este cliente.

### 1. Assinatura visual

Defina uma assinatura visual para o projeto.

A assinatura deve combinar:

- direção visual escolhida
- identidade da marca
- segmento
- público
- posicionamento
- fotografias disponíveis
- conteúdo do cliente

A assinatura visual deve responder:

"Qual característica fará este site parecer especificamente desta marca e não apenas um bom exemplo deste estilo?"

Exemplos de assinatura podem surgir de:

- determinada relação entre tipografia e fotografia
- enquadramentos específicos
- composição assimétrica característica
- uso particular de linhas
- grandes áreas de espaço negativo
- contraste específico de escala
- determinado tratamento de imagens
- formas derivadas da identidade da marca
- ritmo específico entre seções
- um elemento gráfico recorrente

Não invente um elemento decorativo apenas para criar diferenciação.

A assinatura deve surgir naturalmente da marca e da direção escolhida.

### 2. Sistema de composição

Defina como a direção visual afetará:

- Hero
- grid
- alinhamentos
- largura dos conteúdos
- relação entre texto e imagem
- proporções
- espaço negativo
- densidade
- transições entre seções

Não utilize uma estrutura padrão e depois aplique o estilo por cima.

O próprio layout deve nascer da direção escolhida.

### 3. Sistema tipográfico

Defina:

- personalidade tipográfica
- escala
- contraste entre títulos e corpo
- pesos
- tracking quando apropriado
- comportamento dos títulos
- largura dos parágrafos
- uso de labels e microtipografia
- relação entre tipografia e imagens

A tipografia deve contribuir para reconhecer o estilo mesmo sem cores ou fotografias.

### 4. Sistema fotográfico

Defina:

- tipo de enquadramento
- proporções predominantes
- intensidade das imagens
- relação entre fotografia e texto
- tratamento visual
- uso de imagens como fundo, bloco, recorte ou protagonista

Não utilize todas as fotografias da mesma maneira.

Escolha diferentes funções para as imagens dentro da narrativa.

### 5. Sistema de formas

Defina uma lógica para:

- border-radius
- bordas
- linhas
- botões
- containers
- cards
- elementos decorativos

Não utilize automaticamente os padrões visuais do starter.

As formas devem ser consequência da direção escolhida.

### 6. Ritmo da página

Defina como o site alternará:

- impacto
- informação
- fotografia
- respiro
- prova
- conversão

Não mantenha intensidade visual constante durante toda a página.

Crie uma sequência com momentos fortes e momentos silenciosos.

### 7. Elementos distintivos

Escolha entre 1 e 3 recursos visuais característicos para o projeto.

Exemplos:

- numeração editorial
- linhas estruturais
- tipografia oversized
- recortes fotográficos
- molduras
- palavras de grande escala
- composição vertical
- sobreposição
- microtipografia
- grid aparente
- formas derivadas da identidade
- tratamento específico de imagens

Esses recursos devem aparecer de maneira consistente, mas não repetitiva.

Não utilizar todos simultaneamente.

### 8. Adaptação ao cliente

Dois projetos utilizando a mesma direção visual não devem resultar no mesmo site com cores e fotografias diferentes.

Exemplo:

Duas clínicas podem utilizar "Luxury Minimal".

Uma pode resultar em:

- fotografia clara
- serif editorial
- composição delicada
- muito branco
- detalhes finos

Outra pode resultar em:

- tons profundos
- tipografia sans sofisticada
- fotografia dramática
- composição arquitetônica
- contraste forte

A direção é uma linguagem, não um template.

### 9. Intensidade visual

A direção escolhida deve ser adaptada ao nível de intensidade adequado para a marca.

Considere três níveis:

**Contida**
- mais conservadora
- maior previsibilidade
- menor contraste de escala
- composição mais estável

**Expressiva**
- personalidade evidente
- maior contraste
- composições menos previsíveis
- elementos distintivos claros

**Experimental**
- forte direção de arte
- composições incomuns
- grande contraste de escala
- uso mais ousado de grid, tipografia e fotografia

Não utilizar intensidade experimental quando ela prejudicar clareza, confiança, conversão ou adequação ao público.

### 10. Teste de identidade

Antes de considerar a direção visual definida, faça mentalmente três testes.

**Teste sem cor**

Se todas as cores fossem removidas, o estilo ainda seria perceptível através de composição, tipografia, proporção e ritmo?

**Teste sem logo**

Se o logotipo fosse removido, o site ainda possuiria personalidade própria?

**Teste de comparação**

Se o site fosse colocado ao lado de outros projetos criados com este starter, ele pareceria realmente outro projeto?

Se as respostas forem negativas, a direção visual ainda está superficial e deve ser refinada antes da implementação.

## 01 — Minimalista Premium

Ideal para:

arquitetura, advocacia, consultoria, clínicas premium, estética, imobiliário e serviços de alto valor.

### Essência

Transmitir sofisticação através de redução, proporção, espaço e precisão.

O impacto não deve vir da quantidade de elementos, mas da qualidade da composição.

### Composição

- muito espaço negativo
- poucos elementos simultâneos
- grid limpo e preciso
- blocos de conteúdo amplos
- alternância entre conteúdo compacto e grandes áreas de respiro
- alinhamentos rigorosos
- assimetria sutil quando contribuir para sofisticação
- evitar fragmentar excessivamente a página

A composição deve parecer calma, controlada e intencional.

### Tipografia

- títulos grandes e elegantes
- corpo de texto relativamente pequeno e muito legível
- contraste claro de escala
- poucas variações tipográficas
- serif sofisticada ou sans refinada conforme a identidade
- microtipografia discreta
- evitar excesso de pesos diferentes

A tipografia pode ser um dos principais elementos visuais.

### Imagens

- poucas imagens, porém fortes
- fotografias amplas
- enquadramentos limpos
- preferência por imagens com boa composição e espaço negativo
- crops intencionais
- evitar galerias excessivamente carregadas

Uma única fotografia excelente pode ter mais valor visual que várias imagens medianas.

### Hero

Priorizar uma composição elegante e espaçosa.

Possibilidades:

- headline dominante + fotografia ampla
- composição dividida assimétrica
- fotografia fullscreen com poucos elementos
- Hero predominantemente tipográfico
- grande área vazia utilizada intencionalmente

Evitar excesso de badges, ícones, provas, selos ou múltiplos CTAs na primeira dobra.

### Seções

As seções devem possuir bastante respiro.

Preferir:

- texto + imagem
- layouts editoriais simples
- divisores discretos
- listas refinadas
- grandes números quando relevantes
- conteúdo diretamente sobre o fundo

Evitar transformar todas as informações em containers.

### Cards

Utilizar somente quando ajudarem a organização.

Quando necessários:

- simples
- pouco ornamentados
- bordas sutis ou inexistentes
- sombras mínimas ou inexistentes
- radius discreto quando compatível com a marca

Antes de utilizar card, considerar se linha, espaço ou tipografia já são suficientes para separar o conteúdo.

### Formas e detalhes

- linhas finas
- bordas discretas
- formas simples
- poucos elementos decorativos
- botões refinados
- radius controlado
- detalhes pequenos e precisos

Não confundir minimalismo com ausência de design.

### Ritmo

Ritmo predominantemente lento e elegante.

Alternar:

impacto tipográfico → respiro → conteúdo → fotografia → respiro → conversão.

Não manter todas as seções com a mesma densidade.

### Assinatura visual

Escolher 1 ou 2 recursos distintivos adaptados à marca.

Exemplos:

- tipografia oversized
- fotografia com crop característico
- linhas finas estruturais
- numeração discreta
- composição assimétrica
- microtipografia
- grande uso de espaço negativo

Não utilizar todos simultaneamente.

### Intensidade

**Contida**

Composição muito limpa, alinhamentos previsíveis e contraste moderado.

**Expressiva**

Maior contraste de escala, fotografia mais protagonista e assimetria controlada.

**Experimental**

Grandes áreas vazias, tipografia de escala extrema, composições incomuns e relações mais ousadas entre imagem e texto.

Mesmo no nível Experimental, preservar elegância e legibilidade.

### Evitar

- excesso de ícones
- muitos gradientes
- excesso de cards
- sombras evidentes
- excesso de border-radius
- muitas cores
- decoração sem função
- aparência de dashboard/SaaS
- preencher espaços vazios apenas porque parecem vazios
- confundir minimalismo com site simples ou sem personalidade

## 02 — Corporativo Moderno

Ideal para:

empresas B2B, tecnologia, contabilidade, engenharia, indústria, segurança, logística, consultorias e serviços empresariais.

### Essência

Transmitir competência, organização, confiança e modernidade sem parecer burocrático ou genérico.

O design deve comunicar que existe estrutura por trás da empresa.

Modernidade deve surgir principalmente de composição, tipografia, clareza e precisão — não de efeitos decorativos.

### Composição

- grid estruturado
- alinhamentos precisos
- hierarquia clara
- conteúdo bem organizado
- proporções equilibradas
- boa separação entre informação institucional e comercial
- possibilidade de assimetria controlada
- elementos estruturais visíveis quando contribuírem para a identidade

A página pode ser organizada sem parecer rígida.

Evitar construir todas as seções com containers independentes.

### Tipografia

- sans-serif contemporânea como escolha frequente
- títulos objetivos e fortes
- excelente legibilidade
- contraste claro entre headings, corpo e microtextos
- pesos tipográficos utilizados para estruturar informação
- labels e números podem reforçar organização
- tracking controlado

A tipografia deve transmitir precisão e confiança.

Evitar aparência excessivamente informal ou tecnológica quando incompatível com a empresa.

### Imagens

Priorizar fotografias que demonstrem:

- operação
- estrutura
- equipe
- ambiente
- processo
- produto
- instalações
- serviço acontecendo

Sempre que possível, mostrar a empresa real em vez de conceitos corporativos abstratos.

Evitar depender de fotografias genéricas de:

- apertos de mão
- reuniões artificiais
- executivos apontando para telas
- pessoas sorrindo para a câmera sem contexto

### Hero

A proposta de valor deve ser compreendida rapidamente.

Possibilidades:

- texto + fotografia institucional forte
- composição assimétrica com conteúdo e operação
- Hero tipográfico com elementos estruturais
- fotografia ampla com conteúdo sobreposto
- composição modular quando houver informações relevantes

O CTA deve possuir boa visibilidade.

Indicadores ou diferenciais podem aparecer próximos à primeira dobra quando forem reais, relevantes e fornecidos pelo cliente.

Não inventar números para fortalecer visualmente o Hero.

### Seções

Priorizar clareza e organização.

Podem funcionar bem:

- serviços estruturados por linhas ou módulos
- números e indicadores reais
- processos visuais
- cases
- divisores
- timelines
- tabelas simples quando apropriado
- imagens operacionais
- blocos institucionais
- grids estruturados

Nem toda informação precisa virar card.

### Cards

Cards podem ser utilizados com maior frequência neste estilo quando realmente melhorarem a organização.

Quando utilizados:

- hierarquia interna clara
- alinhamentos consistentes
- decoração controlada
- ícones funcionais
- bordas discretas
- contraste suficiente
- boa relação entre título, descrição e ação

Evitar uma página inteira composta por grids de cards idênticos.

### Formas e detalhes

Podem ser utilizados:

- linhas estruturais
- grids aparentes discretos
- formas geométricas
- divisores
- numeração
- indicadores
- pequenos elementos técnicos
- ícones funcionais

Border-radius deve ser moderado e coerente com a identidade.

Evitar arredondamento excessivo que transforme o projeto em interface de SaaS.

### Ritmo

O ritmo deve transmitir eficiência.

Alternar:

proposta de valor → autoridade → solução → operação/processo → prova → conversão.

Áreas mais densas de informação devem ser equilibradas por áreas de respiro ou fotografia.

### Assinatura visual

Escolher 1 ou 2 recursos que expressem organização e identidade.

Exemplos:

- grid aparente
- linhas estruturais
- numeração
- fotografia operacional
- grandes dados reais
- composição modular
- tipografia técnica
- detalhe geométrico derivado da marca

A assinatura deve ser específica para a empresa.

### Intensidade

**Contida**

Grid previsível, composição equilibrada, alta clareza e poucos elementos distintivos.

**Expressiva**

Maior contraste tipográfico, layouts assimétricos controlados, fotografia forte e elementos estruturais mais evidentes.

**Experimental**

Grid mais aparente, tipografia em grande escala, módulos de proporções variadas e composições corporativas menos convencionais.

Mesmo no nível Experimental, preservar confiança, clareza e facilidade de navegação.

### Evitar

- azul corporativo aplicado automaticamente
- fotos genéricas de banco de imagens
- ícones em círculos em todas as seções
- excesso de cards
- aparência de dashboard
- aparência genérica de template empresarial
- excesso de elementos geométricos decorativos
- gradientes utilizados apenas para parecer moderno
- números ou indicadores inventados
- experimentalismo que reduza confiança ou clareza

## 03 — Editorial Sofisticado

Ideal para:

arquitetura, moda, fotografia, gastronomia, design, decoração, estética premium, imobiliário de alto padrão e marcas autorais.

### Essência

Transformar conteúdo em narrativa visual.

O site deve possuir sensação de publicação, campanha ou peça editorial cuidadosamente dirigida, e não de uma sequência convencional de componentes web.

A sofisticação deve surgir principalmente da relação entre tipografia, fotografia, proporção, espaço e ritmo.

### Composição

- assimetria intencional
- grids editoriais
- proporções inesperadas
- grandes contrastes de escala
- elementos alinhados por relações visuais, não apenas por containers
- alternância entre composições densas e áreas vazias
- possibilidade de elementos parcialmente fora do grid
- sobreposição controlada
- layouts menos previsíveis
- forte relação entre imagem e tipografia

A composição pode quebrar padrões convencionais desde que preserve clareza e intenção.

### Tipografia

A tipografia é protagonista.

Priorizar:

- títulos de grande escala
- contraste expressivo entre display e corpo
- quebras de linha cuidadosamente controladas
- serif editorial quando coerente
- sans-serif refinada para contraste ou informação
- itálicos como recurso editorial quando apropriado
- microtipografia
- labels
- numeração
- pequenas legendas

Palavras podem funcionar como elementos gráficos.

Evitar utilizar tipografia grande apenas para parecer sofisticado. Escala deve possuir função dentro da composição.

### Imagens

Fotografia possui papel central.

Priorizar:

- imagens de alta qualidade
- crops expressivos
- enquadramentos editoriais
- fotografias em diferentes escalas
- imagens verticais e horizontais utilizadas intencionalmente
- detalhes
- close-ups
- imagens full-bleed quando apropriado

Não obrigar todas as imagens a possuir a mesma proporção.

A variação de enquadramentos pode fazer parte da narrativa.

### Hero

O Hero deve possuir impacto editorial imediato.

Possibilidades:

- fotografia dominante + headline integrada
- tipografia oversized + imagem secundária
- composição assimétrica entre texto e fotografia
- imagem full-bleed com microtipografia
- composição semelhante a uma capa editorial
- título atravessando ou interagindo visualmente com a imagem
- grande espaço negativo com poucos elementos

O Hero não deve parecer um banner publicitário tradicional.

Mesmo quando visualmente ousado, o negócio e a ação principal devem continuar compreensíveis.

### Seções

Evitar construir todas as seções dentro da mesma largura e estrutura.

Explorar quando apropriado:

- texto estreito ao lado de imagem ampla
- imagem isolada ocupando grande área
- títulos deslocados
- numeração editorial
- citações em grande escala
- listas tipográficas
- composições alternadas
- conteúdo parcialmente sobreposto
- sequências fotográficas
- layouts semelhantes a spreads de revista

Cada seção pode possuir composição própria, desde que pertença ao mesmo sistema visual.

### Cards

Evitar cards convencionais sempre que possível.

Para serviços, projetos, diferenciais ou conteúdos, considerar:

- linhas
- listas editoriais
- imagens
- divisores
- composição tipográfica
- mosaicos
- layouts assimétricos
- blocos sem container visível

Quando cards forem necessários, tratá-los como parte da composição editorial e não como componentes independentes de interface.

### Formas e detalhes

Preferir:

- linhas finas
- divisores
- molduras discretas
- numeração
- labels
- legendas
- elementos gráficos derivados do grid
- detalhes tipográficos

Border-radius geralmente deve ser discreto ou inexistente, salvo quando a identidade da marca justificar outra abordagem.

Sombras raramente devem ser protagonistas.

### Ritmo

O ritmo é fundamental.

Construir sensação de narrativa:

impacto → silêncio → descoberta → detalhe → escala → informação → respiro → conversão.

Evitar manter a mesma densidade durante toda a página.

Algumas seções podem conter apenas uma imagem, uma frase ou um pequeno bloco de conteúdo quando isso fortalecer a narrativa.

### Assinatura visual

Escolher 1 a 3 recursos editoriais característicos.

Exemplos:

- numeração de seções
- headline oversized
- legenda fotográfica
- palavra vertical
- imagem atravessando o grid
- linhas estruturais
- serif + sans
- fotografia com crop característico
- microtipografia
- assimetria recorrente

Esses recursos devem criar identidade sem transformar o site em uma demonstração de efeitos.

### Intensidade

**Contida**

Estrutura editorial elegante, assimetria discreta, fotografia forte e tipografia refinada com boa previsibilidade de leitura.

**Expressiva**

Maior contraste de escala, layouts assimétricos, fotografia dominante, microtipografia e relações mais marcantes entre texto e imagem.

**Experimental**

Tipografia em escala extrema, grids quebrados de maneira controlada, sobreposições, composições inesperadas e narrativa visual mais próxima de uma experiência editorial.

Mesmo no nível Experimental, preservar:

- legibilidade
- entendimento do negócio
- navegação
- CTA
- responsividade
- acessibilidade

### Mobile

Não reduzir simplesmente o layout editorial desktop.

Recompor a narrativa.

No mobile:

- preservar hierarquia
- redefinir sobreposições
- ajustar crops
- controlar títulos oversized
- manter microtipografia legível
- reorganizar assimetrias
- remover elementos que não sobrevivam bem à largura reduzida

O mobile pode possuir composição diferente mantendo a mesma direção de arte.

### Evitar

- aparência de template corporativo
- grids repetitivos de cards
- centralizar todas as seções
- imagens sempre na mesma proporção
- títulos grandes sem propósito
- assimetria aleatória
- sobreposições que prejudiquem leitura
- excesso de elementos editoriais simultâneos
- sacrificar conversão pela estética
- copiar literalmente layouts de revistas ou referências

## 04 — Clean & Humanizado

Ideal para:

saúde, odontologia, psicologia, terapias, educação, bem-estar, estética, profissionais liberais e serviços pessoais.

### Essência

Transmitir proximidade, cuidado, confiança e clareza através de uma experiência visual leve e humana.

O site deve parecer acolhedor sem ser infantil, delicado sem ser frágil e profissional sem ser frio.

Humanização deve surgir principalmente de fotografia, linguagem, espaço, proporção e composição — não apenas de cores suaves e cantos arredondados.

### Composição

- estrutura clara e confortável
- bastante espaço de respiro
- hierarquia simples
- blocos fáceis de compreender
- composição equilibrada
- possibilidade de assimetria suave
- transições naturais entre conteúdo e fotografia
- densidade visual baixa ou moderada
- áreas de conteúdo com largura confortável para leitura

Evitar excesso de containers independentes.

A página deve transmitir tranquilidade e facilidade.

### Tipografia

Priorizar:

- excelente legibilidade
- títulos claros e acolhedores
- escala confortável
- contraste suficiente entre títulos e corpo
- sans-serif humanista ou serif suave quando coerente com a marca
- pesos moderados
- microtipografia discreta

A tipografia pode possuir personalidade, mas não deve criar distância ou formalidade excessiva.

Evitar fontes excessivamente infantis, manuscritas ou delicadas quando prejudicarem credibilidade.

### Imagens

Fotografia é uma das principais ferramentas de humanização.

Priorizar:

- pessoas reais
- profissionais reais
- ambientes reais
- atendimento
- detalhes humanos
- expressões naturais
- interação
- contexto
- luz natural quando disponível

Evitar depender exclusivamente de retratos posados.

Quando houver boas imagens do cliente, utilizar detalhes, enquadramentos e situações diferentes para criar narrativa.

### Hero

O Hero deve criar confiança rapidamente.

Possibilidades:

- pessoa/profissional em destaque + mensagem clara
- fotografia ampla de contexto
- composição assimétrica suave
- retrato editorial + conteúdo
- Hero com bastante espaço negativo
- composição predominantemente tipográfica quando as imagens forem limitadas

O CTA deve ser simples e evidente.

Não sobrecarregar a primeira dobra com muitas provas, selos, badges ou informações.

### Seções

Podem funcionar bem:

- fotografia + texto
- apresentação do profissional ou equipe
- listas de serviços sem containers pesados
- processo explicado de maneira simples
- depoimentos
- perguntas frequentes
- blocos educativos
- pequenos detalhes humanos
- conteúdo com bastante respiro

A experiência deve reduzir insegurança e facilitar entendimento.

### Cards

Cards podem ser utilizados, mas não devem dominar o projeto.

Quando necessários:

- leves
- amigáveis
- boa separação visual
- radius moderado quando coerente
- sombras mínimas
- conteúdo simples
- hierarquia clara

Antes de criar um card, considere se espaço, linha, fotografia ou tipografia já resolvem a organização.

### Formas e detalhes

Podem ser utilizados:

- curvas suaves
- cantos discretamente arredondados
- formas orgânicas simples
- linhas delicadas
- pequenos elementos derivados da identidade
- ícones funcionais
- detalhes gráficos leves

Não utilizar formas arredondadas apenas porque o segmento é saúde ou bem-estar.

### Cores

Cores suaves são permitidas, mas não obrigatórias.

A identidade do cliente possui prioridade.

Clean & Humanizado pode funcionar com:

- neutros
- tons naturais
- cores profundas
- branco predominante
- paletas mais contrastantes

desde que a experiência continue acolhedora e acessível.

Não transformar automaticamente saúde, estética ou bem-estar em paleta bege, rosa, verde-claro ou pastel.

### Ritmo

O ritmo deve ser confortável e natural.

Alternar:

acolhimento → informação → pessoa → serviço → confiança → respiro → conversão.

Evitar sequências longas de blocos densos.

Fotografia e espaço negativo devem ajudar a criar pausas.

### Assinatura visual

Escolher 1 ou 2 elementos coerentes com a personalidade da marca.

Exemplos:

- fotografia humana com enquadramento característico
- serif suave em títulos
- composição assimétrica delicada
- detalhe orgânico derivado da identidade
- linha fina
- pequenas legendas
- tratamento fotográfico específico
- uso característico de espaço negativo

Não transformar "humanizado" em um conjunto fixo de clichês visuais.

### Intensidade

**Contida**

Composição previsível, muito clara, acolhedora e com poucos recursos gráficos.

**Expressiva**

Fotografia mais protagonista, maior contraste tipográfico, assimetria suave e assinatura visual evidente.

**Experimental**

Composição editorial humanizada, fotografias em escalas variadas, tipografia mais expressiva e relações menos convencionais entre imagem e conteúdo.

Mesmo no nível Experimental, preservar sensação de segurança, clareza e proximidade.

### Mobile

No mobile, priorizar:

- leitura confortável
- CTA acessível
- fotografias bem enquadradas
- tamanho adequado dos textos
- espaçamento
- navegação simples

Não permitir que recursos decorativos ocupem espaço que deveria pertencer ao conteúdo.

### Evitar

- aparência excessivamente tecnológica
- interface fria
- excesso de efeitos
- excesso de cards arredondados
- pastel aplicado automaticamente
- rosa automático para marcas femininas
- verde automático para saúde
- fotos de stock excessivamente posadas
- ícones delicados repetidos em todas as seções
- formas orgânicas utilizadas sem propósito
- linguagem visual infantil
- confundir acolhimento com falta de sofisticação

## 05 — Impacto Comercial

Ideal para:

serviços locais, energia solar, construção, automotivo, manutenção, reformas, climatização, segurança, serviços técnicos e negócios orientados à geração de leads.

### Essência

Transformar atenção em ação através de clareza, hierarquia, benefício e confiança.

O visitante deve compreender rapidamente:

- o que a empresa oferece
- por que aquilo é relevante para ele
- quais diferenciais sustentam a oferta
- qual é o próximo passo

Impacto Comercial não significa excesso visual.

A força deve surgir da prioridade correta das informações.

### Composição

- hierarquia visual forte
- leitura rápida
- benefício em destaque
- CTAs evidentes
- blocos comerciais bem definidos
- contraste claro entre informação principal e secundária
- provas posicionadas próximas aos argumentos que sustentam
- ritmo mais dinâmico
- pouca ambiguidade na navegação

A composição deve conduzir o olhar.

Não distribuir atenção igualmente entre todos os elementos.

### Tipografia

Priorizar:

- headlines fortes
- alta legibilidade
- contraste expressivo de escala
- títulos objetivos
- corpo de texto direto
- pesos tipográficos capazes de criar hierarquia
- números em destaque quando forem reais e relevantes

A tipografia deve ajudar o visitante a escanear a página rapidamente.

Evitar utilizar caixa alta, negrito ou cores fortes em excesso.

Quando tudo possui destaque, nada possui destaque.

### Imagens

Priorizar imagens que demonstrem:

- serviço sendo executado
- resultado
- produto
- equipe
- equipamento
- instalação
- ambiente real
- antes/depois quando legítimo e apropriado
- contexto do problema resolvido

Imagens devem ajudar a compreender ou desejar o serviço.

Evitar fotografia meramente decorativa sem relação com a proposta comercial.

### Hero

O Hero deve responder rapidamente:

1. O que está sendo oferecido?
2. Qual benefício principal?
3. Para quem ou onde?
4. O que o visitante deve fazer agora?

Possibilidades:

- headline forte + fotografia do serviço
- benefício + imagem de resultado
- composição dividida
- fotografia de contexto com texto sobreposto
- produto ou serviço visualmente dominante
- Hero predominantemente tipográfico quando houver uma proposta muito forte

O CTA principal deve possuir alta visibilidade.

Um CTA secundário pode existir quando representar uma ação realmente diferente.

### Prova próxima da decisão

Sempre que houver provas reais fornecidas pelo cliente, posicione-as próximas aos argumentos relevantes.

Podem ser utilizadas:

- avaliações reais
- depoimentos
- certificações
- garantias fornecidas
- clientes atendidos quando o número for real
- marcas parceiras autorizadas
- fotografias reais
- cases
- resultados comprovados

Não concentrar obrigatoriamente toda prova social em uma única seção distante.

Não inventar provas para melhorar conversão.

### Seções

Organizar a página como progressão comercial.

Uma lógica possível:

problema ou desejo → solução → benefícios → serviços → diferenciais → processo → prova → objeções → CTA.

Essa sequência não é obrigatória.

Adapte-a ao negócio e à direção de arte.

Evitar repetir a mesma proposta de valor em várias seções apenas com palavras diferentes.

### Cards

Cards podem ser utilizados para facilitar leitura rápida, especialmente em:

- serviços
- benefícios
- diferenciais
- etapas

Mas não transformar a página inteira em cards.

Considere também:

- listas
- linhas
- números
- fotografia + texto
- comparação
- composição modular
- blocos tipográficos
- faixas de conteúdo

Quando houver cards, priorizar clareza e hierarquia sobre decoração.

### CTAs

Deve existir uma ação principal claramente reconhecível ao longo da página.

Não criar cinco estilos diferentes de CTA.

Repita a ação principal em pontos estratégicos.

Os textos dos botões devem indicar ação concreta quando possível.

Exemplos:

- Solicitar orçamento
- Falar pelo WhatsApp
- Agendar avaliação
- Conhecer soluções
- Pedir uma proposta

Evitar pressão artificial.

### Formas e detalhes

Utilizar contraste de maneira estratégica.

Podem funcionar:

- blocos de cor
- faixas
- linhas
- números grandes
- elementos direcionais discretos
- selos reais
- destaques tipográficos
- ícones funcionais

Não adicionar setas, círculos, brilhos e badges em todos os pontos de conversão.

### Ritmo

O ritmo pode ser mais rápido do que em estilos minimalistas.

Alternar:

impacto → benefício → explicação → prova → serviço → confiança → ação.

Seções densas devem ser seguidas por momentos de maior simplicidade.

Não manter sensação de urgência durante toda a página.

### Assinatura visual

Escolher 1 ou 2 elementos capazes de criar reconhecimento sem competir com a conversão.

Exemplos:

- contraste tipográfico forte
- fotografia operacional
- números grandes
- detalhe gráfico derivado da marca
- composição modular
- linhas direcionais
- bloco de cor característico
- tratamento específico dos CTAs

Conversão e identidade visual devem coexistir.

### Intensidade

**Contida**

Alta clareza, estrutura convencional bem executada, CTAs evidentes e poucos elementos gráficos.

**Expressiva**

Headlines maiores, contraste forte, fotografia protagonista, blocos comerciais mais marcantes e ritmo dinâmico.

**Experimental**

Composições comerciais mais ousadas, tipografia de grande escala, assimetria e mudanças expressivas de proporção.

Mesmo no nível Experimental, a proposta, o CTA e a leitura devem permanecer imediatamente compreensíveis.

### Mobile

No mobile, priorizar conversão sem sufocar a experiência.

Garantir:

- proposta compreensível sem scroll excessivo
- CTA principal facilmente acessível
- WhatsApp funcional quando disponível
- textos escaneáveis
- botões confortáveis
- imagens com crop adequado
- provas importantes legíveis

Não empilhar todos os elementos do desktop indiscriminadamente.

Reduza conteúdo secundário quando necessário para preservar hierarquia.

### Evitar

- aparência de página promocional barata
- urgência falsa
- contadores falsos
- escassez artificial
- excesso de vermelho ou cores de alerta
- múltiplos botões competindo entre si
- excesso de badges
- excesso de setas
- textos inteiros em negrito
- provas inventadas
- CTAs em praticamente todos os blocos
- pop-ups agressivos
- poluição visual
- sacrificar identidade da marca em nome da conversão

## 06 — Tech / Futurista

Ideal para:

IA, software, SaaS, automação, startups, tecnologia, inovação, infraestrutura digital e produtos tecnológicos.

### Essência

Transmitir inovação, inteligência, precisão e avanço tecnológico sem depender dos clichês visuais associados à tecnologia.

O projeto deve parecer contemporâneo e tecnologicamente avançado através de composição, interação, tipografia, profundidade e representação do produto.

"Futurista" não significa obrigatoriamente escuro, neon, roxo ou cheio de efeitos.

### Composição

Priorizar:

- grids estruturados ou modulares
- contraste de escala
- composição precisa
- camadas visuais controladas
- relação entre interface, conteúdo e espaço
- possibilidade de assimetria
- profundidade quando relevante
- grandes áreas de respiro
- elementos técnicos integrados à composição

A página deve transmitir sistema e inteligência.

Evitar preencher todos os espaços com elementos abstratos apenas para comunicar tecnologia.

### Tipografia

Priorizar:

- sans-serif contemporânea
- alta legibilidade
- títulos fortes
- contraste expressivo de escala
- microtipografia técnica quando apropriada
- labels
- números
- códigos ou dados somente quando possuírem função real
- tracking controlado

A tipografia pode assumir aparência extremamente limpa ou mais experimental dependendo da marca.

Não utilizar fontes "futuristas" decorativas apenas para comunicar tecnologia.

### Cores

A identidade do cliente possui prioridade.

Tech / Futurista pode utilizar:

- fundos claros
- fundos escuros
- monocromia
- alto contraste
- paletas neutras
- cores vibrantes
- gradientes

Não aplicar automaticamente:

preto + roxo + azul + glow.

Gradientes devem possuir função dentro da composição e não servir como atalho para "aparência de IA".

### Produto como protagonista

Quando existir interface, plataforma, aplicativo ou produto digital real, ele deve possuir prioridade sobre abstrações decorativas.

Considere:

- screenshots reais
- recortes de interface
- detalhes ampliados
- composição em camadas
- demonstrações de funcionalidades
- fluxos visuais
- mockups discretos
- interface integrada ao Hero

Não inventar telas ou funcionalidades que o produto não possui.

### Imagens e elementos gráficos

Quando não houver interface como protagonista, podem ser utilizados:

- fotografia tecnológica
- produto físico
- infraestrutura
- ambientes
- detalhes técnicos
- formas abstratas
- grids
- linhas
- partículas discretas
- diagramas visuais
- texturas digitais

Elementos abstratos devem reforçar a composição e não apenas preencher o fundo.

### Hero

O Hero deve transmitir inovação imediatamente sem prejudicar entendimento do produto.

Possibilidades:

- produto/interface dominante
- headline forte + demonstração visual
- composição tipográfica com elementos técnicos
- composição modular
- interface parcialmente fora do viewport
- visual abstrato proprietário
- fotografia tecnológica de alto impacto
- Hero claro e minimalista com pequenos detalhes digitais

Evitar construir automaticamente:

headline centralizada + gradiente roxo + dashboard flutuante + glow.

### Profundidade

Profundidade pode ser utilizada através de:

- sobreposição
- blur controlado
- transparência
- camadas
- grids
- luz
- contraste
- movimento
- escala

Não utilizar todos simultaneamente.

Glassmorphism deve ser utilizado somente quando fizer sentido para a direção visual e nunca como linguagem automática de tecnologia.

### Cards

Cards podem funcionar bem em produtos digitais, mas devem possuir propósito.

Quando utilizados:

- organização modular
- hierarquia clara
- contraste controlado
- superfícies coerentes
- bordas discretas
- profundidade sutil quando necessária

Evitar transformar cada feature em uma caixa luminosa independente.

Considere também:

- Bento Grid
- listas técnicas
- interface demonstrativa
- módulos de tamanhos diferentes
- linhas
- composição tipográfica
- demonstrações do produto

### Seções

Podem funcionar bem:

- demonstrações de produto
- funcionalidades
- integrações
- fluxos
- comparações
- casos de uso
- arquitetura simplificada
- métricas reais
- depoimentos
- processos
- CTAs

Sempre traduzir tecnologia em benefício compreensível.

Não permitir que o design faça o produto parecer mais complexo do que realmente é.

### Microinterações

Este estilo permite maior presença de microinterações quando contribuírem para percepção de produto e qualidade.

Podem ser utilizadas:

- hover states refinados
- movimentos sutis
- mudanças de estado
- revelação progressiva
- parallax discreto
- animações de interface
- transições

Priorizar performance.

Movimento deve responder a uma intenção.

Não animar elementos apenas porque é tecnicamente possível.

### Formas e detalhes

Podem funcionar:

- linhas técnicas
- grids
- coordenadas
- numeração
- pequenos indicadores
- detalhes geométricos
- superfícies
- recortes
- divisores
- elementos inspirados na própria interface do produto

Sempre que possível, derive a linguagem gráfica do próprio produto ou marca.

### Ritmo

Alternar:

impacto → produto → benefício → funcionamento → prova → detalhe → conversão.

Momentos tecnologicamente densos devem ser equilibrados com áreas simples.

Não manter glow, movimento e informação intensa durante toda a experiência.

### Assinatura visual

Escolher 1 a 3 recursos distintivos.

Exemplos:

- interface como elemento gráfico
- grid técnico
- microtipografia
- movimento específico
- tratamento de luz
- composição modular
- linhas estruturais
- detalhe inspirado no produto
- contraste tipográfico
- visualização de dados reais

A assinatura deve ajudar a reconhecer a marca, não apenas o segmento tecnológico.

### Intensidade

**Contida**

Interface limpa, composição precisa, poucos efeitos e tecnologia comunicada principalmente pelo produto.

**Expressiva**

Maior contraste, profundidade controlada, elementos técnicos, layouts modulares e produto visualmente dominante.

**Experimental**

Composições espaciais, escalas extremas, interfaces fragmentadas, movimento mais presente e relações menos convencionais entre conteúdo e produto.

Mesmo no nível Experimental, preservar:

- clareza
- performance
- legibilidade
- navegação
- compreensão do produto
- conversão

### Mobile

No mobile:

- priorizar mensagem e produto
- reduzir camadas desnecessárias
- simplificar efeitos
- adaptar interfaces demonstrativas
- evitar screenshots ilegíveis
- controlar animações
- preservar performance
- recompor layouts modulares

Não simplesmente reduzir uma composição complexa de desktop.

### Evitar

- estética genérica de "IA roxa"
- neon exagerado
- glow em todos os elementos
- partículas gratuitas
- glassmorphism automático
- dashboards fictícios
- interfaces inventadas
- código aleatório como decoração
- excesso de gradientes
- excesso de blur
- fundo escuro obrigatório
- animações gratuitas
- estética gamer quando não fizer parte da marca
- sacrificar clareza pela sensação de futurismo

## 07 — Orgânico / Natural

Ideal para:

Transmitir autenticidade, proximidade, matéria, natureza e conexão humana.

A sensação orgânica deve surgir da relação entre fotografia, textura, formas, espaço e ritmo.

O estilo pode assumir uma interpretação:

- sofisticada
- artesanal
- contemporânea
- tropical
- minimalista
- rústica
- editorial

- ritmo menos rígido
- assimetria suave
- espaços generosos
- relação natural entre texto e imagem
- blocos com diferentes proporções
- imagens integradas ao fluxo da página
- sensação de movimento e continuidade
- possibilidade de elementos parcialmente fora do grid
- estrutura visual menos mecânica

Podem funcionar:

- serifas orgânicas
- serifas editoriais
- sans humanistas
- tipografias de aparência artesanal quando altamente controladas

- matéria
- detalhes
- imperfeições reais

- natureza
- pessoas em contexto
- processo
- produto em uso
- close-ups
- fotografias atmosféricas

Utilizar diferentes escalas e enquadramentos para criar sensação de descoberta.

Evitar imagens excessivamente artificiais ou esterilizadas quando forem incompatíveis com a marca.

- grão
- madeira
- pedra
- tecido
- terra
- vegetação
- superfícies naturais
- imperfeições

Não utilizar textura apenas para fazer o projeto parecer artesanal.

Ela deve possuir relação com a marca ou produto.

### Hero

O Hero deve criar atmosfera sem perder clareza.

Possibilidades:

- fotografia ambiental ampla
- imagem full-bleed
- composição editorial com fotografia
- produto em contexto

- detalhe natural em grande escala

Podem funcionar bem:

- fotografia + texto
- sequências fotográficas
- histórias de origem
- processos
- ingredientes ou materiais
- experiências
- detalhes do produto
- áreas de atuação
- valores
- composição editorial
- listas sem containers visíveis

Permitir que fotografia e espaço contem parte da história.

### Cards

Cards devem ser utilizados com moderação.

Quando necessários:

- formas suaves quando coerentes
- integração com imagens
- pouco peso visual
- materiais e texturas podem possuir protagonismo
- bordas e sombras discretas

Considere antes:

- listas
- imagens
- composição editorial
- divisores
- blocos tipográficos
- mosaicos

Podem funcionar:

- curvas
- recortes
- formas irregulares
- linhas desenhadas
- molduras
- texturas
- detalhes botânicos
- elementos derivados de materiais reais
- formas inspiradas na própria identidade

Não utilizar blobs aleatórios como atalho para parecer orgânico.

### Cores

A paleta deve derivar da marca e do universo visual do negócio.

Não assumir automaticamente:

verde + bege + marrom.

Orgânico / Natural também pode funcionar com:

- preto e branco
- cores profundas
- tons minerais
- cores tropicais
- tons terrosos
- paletas claras
- alto contraste

desde que exista coerência com a marca.

O ritmo deve possuir sensação natural de descoberta.

Alternar:

atmosfera → história → detalhe → produto/serviço → respiro → experiência → conversão.

Evitar repetição mecânica de seções iguais.

### Assinatura visual

Escolher 1 a 3 recursos coerentes com o universo da marca.

Exemplos:

- textura específica
- crop fotográfico
- forma derivada de um elemento natural
- composição assimétrica
- serif característica
- moldura
- fotografia macro
- detalhe artesanal
- linha orgânica
- sobreposição sutil

A assinatura deve parecer pertencente à marca, não a um template ecológico.

### Intensidade

**Contida**

Composição limpa, fotografia natural, pequenas referências orgânicas e estrutura relativamente previsível.

**Expressiva**

Maior protagonismo fotográfico, texturas sutis, assimetria e relações mais livres entre elementos.

**Experimental**

Composição altamente visual, recortes, materialidade, tipografia expressiva, imagens em escalas variadas e fluxo menos convencional.

Mesmo no nível Experimental, preservar legibilidade e clareza.

### Mobile

No mobile:

- preservar impacto das fotografias

- manter leitura confortável
- preservar sensação de espaço

- aparência tecnológica incompatível

- texturas artificiais sem relação com a marca

- excesso de elementos artesanais
- confundir natural com rústico
- sacrificar clareza em nome da atmosfera

## 08 — Bold Contemporâneo

Ideal para:

agências, criadores, eventos, academias, esportes, entretenimento, moda urbana, marcas jovens e empresas que desejam forte personalidade.

### Essência

Criar impacto imediato através de tipografia, escala, contraste e composição.

O projeto deve possuir energia e personalidade visual forte sem depender de uma grande quantidade de efeitos.

Bold não significa adicionar mais elementos.

Significa tornar determinadas decisões visuais mais fortes.

### Composição

Priorizar:

- grandes contrastes de escala
- blocos visuais fortes
- assimetria intencional
- elementos oversized
- mudanças expressivas de proporção
- áreas densas contrastando com áreas vazias
- composições que ultrapassam o grid quando apropriado
- relações fortes entre texto e imagem
- layouts menos previsíveis
- ritmo visual dinâmico

A página deve possuir momentos capazes de gerar impacto mesmo sem animação.

### Tipografia

Tipografia é um dos principais protagonistas.

Podem funcionar:

- sans-serif pesada
- grotesk
- condensed
- display contemporânea
- serif expressiva quando coerente
- combinações tipográficas de alto contraste

Explorar:

- títulos oversized
- palavras ocupando grande parte da viewport
- contraste extremo entre display e corpo
- caixa alta
- tracking
- linhas curtas
- palavras isoladas
- números grandes

Não utilizar tipografia extrema em todos os textos.

O contraste depende da existência de elementos menores e silenciosos.

### Imagens

As imagens devem possuir energia compatível com a composição.

Priorizar:

- enquadramentos fortes
- movimento
- ação
- close-ups
- cortes inesperados
- detalhes
- perspectivas incomuns
- fotografias com contraste
- pessoas ou produtos em poses expressivas

A imagem pode ser parcialmente escondida, cortada ou atravessada pela tipografia quando isso preservar entendimento.

Evitar fotografia genérica excessivamente neutra quando a marca exige impacto.

### Hero

O Hero deve estabelecer personalidade imediatamente.

Possibilidades:

- headline ocupando grande parte da tela
- tipografia + fotografia sobrepostas
- composição assimétrica
- fotografia full-bleed
- palavra ou frase como principal elemento gráfico
- produto/pessoa em escala ampliada
- split screen com proporções incomuns
- composição tipográfica quase sem imagem
- texto parcialmente atravessando a imagem

Evitar Hero convencional apenas decorado com elementos "ousados".

A própria estrutura deve ser ousada.

### Seções

As seções podem explorar:

- títulos gigantes
- números
- listas de grande escala
- fotografias full-width
- mosaicos
- layouts alternados
- conteúdo horizontal quando apropriado
- palavras como elementos gráficos
- composição modular
- blocos de cor
- elementos parcialmente fora do viewport

Nem toda seção precisa ser intensa.

Se tudo for Bold, nada parecerá Bold.

### Cards

Evitar cards convencionais como solução automática.

Quando forem utilizados, podem possuir:

- escalas diferentes
- proporções diferentes
- tipografia dominante
- fotografia
- contraste forte
- composição assimétrica

## 12 — Immersive / Cinematic

Ideal para:

arquitetura, hotelaria, turismo, gastronomia, empreendimentos imobiliários, eventos, moda, automóveis e marcas com forte potencial fotográfico ou narrativo.

### Essência

Criar uma experiência visual envolvente através de escala, fotografia, narrativa, ritmo e composição.

Immersive / Cinematic deve fazer o visitante sentir que está entrando no universo da marca.

A imersão deve surgir principalmente de:

- imagens
- proporção
- enquadramento
- sequência
- espaço
- tipografia
- ritmo
- transições

Não depender de animações complexas para criar impacto.

Uma página completamente estática ainda deve parecer cinematográfica.

### Narrativa

Pensar a página como uma sequência de cenas.

Cada seção deve possuir um papel dentro da experiência.

Uma possível progressão:

abertura → atmosfera → descoberta → detalhe → contexto → experiência → informação → prova → conversão.

Não revelar tudo na primeira dobra.

Distribuir informação e impacto ao longo da página.

O scroll deve produzir sensação de descoberta.

### Composição

Priorizar:

- imagens de grande escala
- seções amplas
- mudanças de proporção
- enquadramentos fortes
- conteúdo integrado à fotografia
- áreas de silêncio
- alternância entre proximidade e amplitude
- composição editorial
- sobreposição controlada
- assimetria quando apropriada
- mudanças de densidade

Evitar transformar toda seção em fullscreen.

A imersão depende da variação de escala.

### Fotografia

Fotografia é protagonista.

Priorizar:

- imagens de alta qualidade
- enquadramentos cinematográficos
- diferentes distâncias
- planos abertos
- planos médios
- detalhes
- close-ups
- texturas
- pessoas em contexto
- arquitetura
- ambiente
- produto
- luz e sombra

Utilizar sequências capazes de contar uma história.

Não repetir continuamente o mesmo tipo de enquadramento.

### Direção de imagem

Ao selecionar imagens, pensar em função narrativa.

Uma imagem pode servir como:

- establishing shot
- protagonista
- detalhe
- atmosfera
- contexto
- transição
- prova
- encerramento

Não utilizar imagens apenas porque são visualmente bonitas.

Cada fotografia deve possuir um papel.

### Hero

O Hero deve funcionar como abertura cinematográfica.

Possibilidades:

- fotografia fullscreen
- vídeo real fornecido pelo cliente
- imagem quase fullscreen
- headline integrada à fotografia
- composição minimalista sobre imagem
- sequência visual
- arquitetura ou ambiente dominante
- produto em grande escala
- composição tipográfica com imagem secundária

Utilizar poucos elementos.

A primeira dobra deve criar curiosidade sem esconder o que a empresa faz.

### Tipografia

Tipografia deve coexistir com as imagens.

Podem funcionar:

- títulos grandes
- serifas editoriais
- sans sofisticadas
- tipografia condensada
- microtipografia
- legendas
- labels
- frases curtas
- títulos integrados ao enquadramento

Evitar colocar grandes blocos de texto sobre imagens complexas.

Legibilidade possui prioridade.

### Seções

Explorar diferentes experiências ao longo da página.

Podem funcionar:

- imagem fullscreen
- fotografia vertical isolada
- imagem pequena cercada por espaço negativo
- mosaicos
- sequências fotográficas
- texto sobre imagem
- texto ao lado de imagem
- composição editorial
- detalhes ampliados
- galerias cuidadosamente dirigidas
- blocos tipográficos
- seções de informação mais simples

A alternância é fundamental.

Depois de uma seção visualmente intensa, considere uma seção silenciosa.

### Escala cinematográfica

Criar contraste entre:

- amplo e íntimo
- cheio e vazio
- imagem e texto
- claro e escuro
- movimento e pausa
- grande e pequeno

Não manter todos os elementos em escala monumental.

Um detalhe pequeno pode aumentar o impacto da próxima imagem grande.

### Cards

Cards não devem ser a linguagem principal.

Quando informações precisarem ser agrupadas, considerar primeiro:

- composição editorial
- listas
- linhas
- tipografia
- fotografia
- painéis integrados à narrativa
- divisões espaciais

Cards podem existir em áreas funcionais, mas não devem interromper a experiência visual sem necessidade.

### Movimento

Movimento é opcional.

Quando utilizado, deve reforçar narrativa, profundidade ou transição.

Podem funcionar:

- fade discreto
- reveal
- movimento suave de imagem
- parallax muito controlado
- transições de escala
- mudanças sutis de posição
- vídeo
- sticky sections quando realmente justificadas

Não utilizar movimento apenas para impressionar.

Evitar:

- scroll hijacking
- animações longas bloqueando conteúdo
- excesso de parallax
- elementos perseguindo o cursor
- transições que atrasem navegação
- movimento constante em toda a página

Respeitar `prefers-reduced-motion`.

### Vídeo

Vídeo somente deve ser utilizado quando existir material adequado.

Não inventar dependência de vídeo quando o cliente não forneceu esse conteúdo.

Quando utilizado:

- otimizar arquivo
- considerar poster
- evitar áudio automático
- preservar legibilidade
- possuir fallback
- avaliar impacto de performance
- não bloquear conteúdo essencial

Fotografia excelente é preferível a vídeo ruim.

### Profundidade

Profundidade pode surgir através de:

- escala
- sobreposição
- fotografia
- perspectiva
- luz
- sombra
- movimento sutil
- elementos parcialmente fora do enquadramento

Não depender de blur, glow ou glassmorphism para criar profundidade.

### Ritmo

O ritmo é um dos elementos mais importantes deste estilo.

Uma possibilidade:

impacto → silêncio → detalhe → descoberta → amplitude → informação → atmosfera → prova → encerramento.

Criar pausas.

Não tentar impressionar o visitante em todos os segundos da experiência.

### Assinatura visual

Escolher 1 a 3 recursos característicos.

Exemplos:

- tipo específico de enquadramento
- transição entre escalas
- fotografia full-bleed
- legendas cinematográficas
- numeração de cenas
- tipografia integrada à imagem
- sequência de detalhes
- uso característico de luz
- composição vertical
- alternância entre fullscreen e grande espaço negativo

A assinatura deve pertencer à marca e ao conteúdo disponível.

### Intensidade

**Contida**

Fotografia forte, seções amplas, ritmo elegante e pouca ou nenhuma animação.

**Expressiva**

Imagens em grande escala, narrativa visual evidente, mudanças de proporção, tipografia integrada e transições sutis.

**Experimental**

Composição imersiva, escalas extremas, sticky storytelling, sobreposições, transições espaciais e movimento mais presente.

Mesmo no nível Experimental, preservar:

- navegação
- performance
- acessibilidade
- clareza
- responsividade
- conversão
- controle do usuário

### Mobile

No mobile, reconstruir a experiência cinematográfica.

Não tentar reproduzir literalmente a composição desktop.

Priorizar:

- crops verticais
- imagens em escala adequada
- sequência narrativa
- legibilidade
- performance
- espaço
- redução de sobreposições
- redução de animações
- CTA acessível

Uma experiência mobile pode utilizar uma sequência visual diferente do desktop se isso preservar melhor a intenção narrativa.

### Performance

Experiência premium exige performance.

O estilo visual nunca justifica:

- imagens gigantes sem otimização
- vídeos desnecessários
- JavaScript excessivo
- animações pesadas
- layout shift
- carregamento inicial lento

Priorizar:

- formatos modernos de imagem
- carregamento responsivo
- lazy loading quando apropriado
- otimização de vídeo
- animações baseadas em transform e opacity
- redução de dependências

Impacto visual e performance devem coexistir.

### Diferença para Dark Luxury

Dark Luxury prioriza:

- atmosfera escura
- dramaticidade
- contraste
- luz
- profundidade

Immersive / Cinematic prioriza:

- narrativa
- fotografia
- escala
- sequência
- descoberta
- experiência durante o scroll

Immersive / Cinematic não precisa ser escuro.

Pode ser claro, solar, colorido ou natural.

### Evitar

- animação em todas as seções
- parallax excessivo
- scroll hijacking
- vídeo obrigatório
- texto ilegível sobre fotografia
- fullscreen em todas as seções
- imagens grandes sem função narrativa
- excesso de sobreposição
- efeitos que prejudicam performance
- depender de JavaScript para criar impacto
- experiência desktop impossível de utilizar no mobile
- confundir imersão com complexidade
- transformar o site em uma demonstração técnica

# Uso de referências externas

Caso o projeto possua referências visuais fornecidas pelo cliente, elas devem ser analisadas juntamente com este catálogo.

A referência externa pode servir para identificar:
- composição
- densidade
- estilo tipográfico
- uso de imagens
- ritmo
- nível de minimalismo
- formas
- comportamento das seções

Não copiar literalmente outro site.

Utilizar a referência como direção visual e reinterpretá-la para a identidade e o conteúdo do cliente.

# Regra de seleção da direção visual

A escolha da direção visual deve acontecer somente depois da leitura completa do briefing, identidade disponível, conteúdo, imagens e contexto do cliente.

Não escolher estilo apenas pelo segmento.

Empresas do mesmo segmento podem exigir direções completamente diferentes.

A direção visual deve ser consequência do posicionamento da marca.

## 1. Analise o cliente antes de escolher

Considere em conjunto:

- segmento
- posicionamento
- público
- faixa de preço
- percepção de valor desejada
- personalidade da marca
- identidade visual existente
- objetivo principal do site
- tipo e qualidade do conteúdo
- quantidade e qualidade das imagens
- produto ou serviço
- nível de confiança necessário
- complexidade da informação
- necessidade de conversão
- concorrentes quando fornecidos
- referências visuais quando fornecidas

Não escolha uma direção visual antes dessa análise.

## 2. Defina a sensação principal

Antes de selecionar o estilo, responda:

**Qual deve ser a principal sensação transmitida nos primeiros segundos?**

Exemplos:

- confiança
- exclusividade
- inovação
- proximidade
- energia
- autoridade
- desejo
- tranquilidade
- precisão
- impacto
- sofisticação
- naturalidade

Escolha uma sensação principal e, no máximo, duas secundárias.

Evite tentar comunicar tudo simultaneamente.

## 3. Identifique a necessidade dominante

Determine qual necessidade possui maior peso no projeto.

Exemplos:

**Clareza e sofisticação**
→ considerar Minimalista Premium.

**Organização, confiança e competência**
→ considerar Corporativo Moderno.

**Expressão visual, conteúdo e fotografia**
→ considerar Editorial Sofisticado.

**Proximidade, cuidado e confiança**
→ considerar Clean & Humanizado.

**Conversão, benefício e ação**
→ considerar Impacto Comercial.

**Inovação, produto e tecnologia**
→ considerar Tech / Futurista.

**Natureza, matéria e autenticidade**
→ considerar Orgânico / Natural.

**Energia, personalidade e impacto**
→ considerar Bold Contemporâneo.

**Exclusividade, desejo e curadoria**
→ considerar Luxury Minimal.

**Atmosfera, dramaticidade e profundidade**
→ considerar Dark Luxury.

**Estrutura, tipografia e precisão gráfica**
→ considerar Swiss / International.

**Narrativa, fotografia e experiência**
→ considerar Immersive / Cinematic.

Essas associações são orientações, não regras fixas por segmento.

## 4. Escolha uma direção principal

Todo projeto deve possuir:

**1 direção visual principal.**

Ela deve controlar principalmente:

- composição
- Hero
- grid
- tipografia
- fotografia
- ritmo
- formas
- cards
- espaçamento
- detalhes
- comportamento visual geral

Não misture vários estilos com o mesmo peso.

A direção principal deve permanecer reconhecível ao longo de toda a página.

## 5. Direção secundária

Uma segunda direção pode ser utilizada somente quando resolver uma necessidade real do projeto.

Ela funciona como influência, não como segundo estilo completo.

Exemplos:

Luxury Minimal + influência Editorial Sofisticada.

Corporativo Moderno + influência Swiss / International.

Clean & Humanizado + influência Minimalista Premium.

Impacto Comercial + influência Bold Contemporâneo.

Tech / Futurista + influência Swiss / International.

Orgânico / Natural + influência Immersive / Cinematic.

A direção secundária deve afetar apenas determinados aspectos.

Exemplo:

**Direção principal:** Clean & Humanizado  
**Influência:** Editorial Sofisticado  
**Resultado:** experiência acolhedora com fotografia e composição mais editorial.

Não criar uma mistura 50/50.

Como referência:

- direção principal: aproximadamente 70–90% da linguagem
- influência secundária: aproximadamente 10–30%

Esses percentuais são conceituais, não matemáticos.

## 6. Não misturar por decoração

Não utilizar uma direção secundária apenas para adicionar:

- gradientes
- glow
- formas orgânicas
- serifas
- animações
- dourado
- grids
- cards
- assimetria

Recursos visuais isolados não constituem uma direção de arte.

A mistura deve possuir justificativa estratégica.

## 7. Compatibilidade com os ativos

A direção escolhida deve funcionar com os materiais realmente disponíveis.

Exemplo:

Não escolher uma experiência Immersive / Cinematic altamente dependente de fotografia quando o cliente possui apenas duas imagens pequenas e de baixa qualidade.

Não construir uma direção Tech baseada em demonstração de produto se não existe interface real disponível.

Não escolher uma direção Editorial altamente fotográfica se o conteúdo visual não sustenta essa abordagem.

Quando os ativos forem limitados, adapte a direção de arte em vez de inventar materiais.

## 8. Compatibilidade com conteúdo

A quantidade de conteúdo também influencia a escolha.

Projetos com muita informação podem exigir:

- grids
- hierarquia
- navegação clara
- modularidade
- estrutura tipográfica

Projetos com pouco conteúdo podem explorar melhor:

- escala
- espaço
- fotografia
- ritmo
- composição

Não tentar esconder conteúdo complexo dentro de uma direção excessivamente minimalista.

Não preencher artificialmente projetos com pouco conteúdo.

## 9. Compatibilidade com conversão

A direção visual nunca deve impedir o objetivo comercial.

Um site sofisticado ainda precisa permitir:

- compreender a proposta
- encontrar serviços
- confiar na empresa
- realizar a ação principal

Conversão não exige Impacto Comercial como direção principal.

Luxury Minimal, Editorial, Swiss, Cinematic e outros estilos também podem converter.

Adapte a forma do CTA à direção visual sem esconder a ação.

## 10. Compatibilidade com o público

Considere o repertório e as expectativas do público.

Uma direção extremamente experimental pode funcionar para:

- agência criativa
- moda
- arquitetura
- design
- entretenimento

e ser inadequada para determinados projetos que dependem de previsibilidade, rapidez ou confiança institucional.

Não escolher a direção que parece mais interessante para o designer.

Escolha a direção que melhor representa a marca para o público correto.

## 11. Intensidade

Depois de escolher a direção, defina:

- Contida
- Expressiva
- Experimental

A intensidade deve considerar:

- personalidade da marca
- público
- posicionamento
- conteúdo
- objetivo
- qualidade dos ativos
- tolerância à experimentação

Na dúvida, utilizar **Expressiva** quando o briefing pedir um site visualmente marcante e houver ativos suficientes para sustentá-lo.

Não escolher Experimental apenas para produzir algo diferente.

## 12. Justificativa obrigatória

Antes de iniciar a implementação, registre internamente:

**Direção principal:**  
[nome]

**Influência secundária:**  
[nome ou nenhuma]

**Intensidade:**  
[Contida / Expressiva / Experimental]

**Sensação principal:**  
[uma]

**Sensações secundárias:**  
[até duas]

**Protagonista visual:**  
[tipografia / fotografia / produto / conteúdo / outro]

**Motivo da escolha:**  
[explicação objetiva baseada no briefing]

**Recursos de assinatura:**  
[1 a 3]

**O que evitar neste projeto:**  
[principais riscos de cair em template ou clichê]

A implementação só deve começar depois dessas decisões.

## 13. Teste de coerência

Antes de implementar, responda:

1. Essa direção representa o posicionamento real do cliente?
2. Ela funciona com as imagens e conteúdos disponíveis?
3. Ela faz sentido para o público?
4. Ela favorece o objetivo principal do site?
5. Existe uma direção mais adequada?
6. A influência secundária possui uma função clara?
7. O resultado continuará reconhecível como a direção principal?
8. Estou escolhendo isso por estratégia ou apenas porque parece visualmente interessante?

Se alguma resposta revelar incoerência, revise a escolha.

## 14. Teste anti-template

Imagine três empresas diferentes do mesmo segmento utilizando a mesma direção visual.

Os três sites deveriam continuar diferentes entre si por causa de:

- identidade
- posicionamento
- conteúdo
- fotografia
- composição
- assinatura visual
- intensidade

Se a única diferença provável for:

- logo
- cores
- textos
- fotografias

a direção ainda está sendo tratada como template.

Refaça a interpretação antes de implementar.
