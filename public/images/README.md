# Imagens do Cliente

Coloque nesta pasta as imagens fornecidas pelo cliente que podem ser utilizadas no site.

Exemplos:

- fotos da empresa
- fotos da equipe
- fotos dos serviços
- fotos de produtos
- fotos do espaço físico
- imagens de projetos ou trabalhos realizados
- banners e materiais institucionais

## Regras

Priorize as imagens reais fornecidas pelo cliente sempre que forem adequadas ao conteúdo.

O Agent deve analisar os arquivos disponíveis nesta pasta antes de definir quais imagens serão utilizadas no site.

Não presumir o conteúdo de uma imagem apenas pelo nome do arquivo.

Não utilizar uma imagem em contexto que possa gerar uma interpretação incorreta sobre a empresa, serviço ou produto.

Preservar a proporção das imagens e escolher `object-cover` ou `object-contain` conforme o contexto visual.
