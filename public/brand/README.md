# Identidade Visual do Cliente

Coloque nesta pasta os arquivos oficiais da identidade visual fornecidos pelo cliente.

Exemplos:

- logo principal
- versões alternativas do logo
- favicon
- manual de identidade visual
- paleta de cores
- elementos gráficos da marca
- ícones próprios

## Regras

Os arquivos fornecidos aqui devem ser priorizados na criação do site.

Não substituir a identidade visual oficial por elementos genéricos sem necessidade.

O Agent deve analisar os materiais disponíveis nesta pasta antes de definir a direção visual do site.
